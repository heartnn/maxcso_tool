# 🎮 maxcso_tool

一个专为 PSP 玩家（尤其是实机党）准备的“傻瓜式”镜像压缩/解压小工具。

受够了老版 `ciso.exe` 压不了 2GB 以上的大游戏？压出来的 CSO 在实机上玩的时候卡成 PPT、疯狂爆音？
这个小工具帮你一键搞定！底层采用现代压缩神器 `maxcso`，速度快到飞起，而且**完美保证 PSP 实机流畅运行**。

## ✨ 特色功能

- 🚀 **告别 2G 限制**：老工具压大文件会直接崩溃吐空文件，这个工具轻松拿捏 2GB 甚至更大的 ISO。
- 🏀 **实机丝滑不卡顿**：默认 `2048` 块大小。这是 PSP 实机读盘的“黄金参数”，拒绝过场动画掉帧和死机。
- 🧠 **自动判断，无脑操作**：拖入 `.iso` 自动压缩，拖入 `.cso` 自动解压，不用你手动选模式。
- ⚡ **极速压缩**：采用 `--fast` 模式，利用多核 CPU 优势，压缩率媲美老工具的 9 级，但速度快几倍。

## 🕹️ 使用方法

### 方法一：拖拽大法（最推荐，像快攻上篮一样简单）
直接把游戏文件**拖拽**到 `maxcso_tool.exe` 的图标上：
- 拖入 `.iso` 👉 在同目录下生成压缩后的 `.cso`。
- 拖入 `.cso` 👉 在同目录下生成解压后的 `.iso`。

### 方法二：双击运行
直接双击打开工具，会弹出一个黑色窗口。把文件拖进窗口里（或者手动输入文件路径），按下回车键，它就会自动开始干活。

## 🛠️ 源码 & 打包指南

如果你想自己修改代码，或者想自己打包成 EXE，请看这里：

### 1. 直接运行 Python 源码
1. 确保你安装了 Python（建议 3.8 以上）。
2. 下载 [maxcso](https://github.com/unknownbrackets/maxcso/releases)，把 `maxcso.exe` 放在和 `maxcso_tool.py` **同一个文件夹**里。
3. 双击运行 `maxcso_tool.py` 即可。

### 2. 打包成单文件 EXE
打包后的 EXE 会把 `maxcso.exe` 直接“吃”进肚子里，不需要带一堆乱七八糟的文件，放在 U 盘里走到哪用到哪。

1. 安装打包工具：在命令行运行 `pip install pyinstaller`。
2. 把 `maxcso_tool.py` 和 `maxcso.exe` 放在同一个文件夹。
3. 在该文件夹下打开命令行，运行以下命令：

```bash
pyinstaller -F --add-data "maxcso.exe;." maxcso_tool.py
```
打包完成后，编译成功的文件在在 `dist/maxcso_tool.exe`。

## 💡 实机玩家避坑指南

1. 路径尽量保持干净：虽然工具兼容性不错，但为了避免玄学报错，游戏文件的路径最好是纯英文、无空格。比如 D:\PSP\GAME.iso 就比 D:\我的游戏\Naruto Shippuden.iso 稳妥得多。
2. 为什么是 2048 块大小？：PSP 实机的 CPU 性能比较弱。如果块大小太小，CPU 解压次数会成倍增加，导致游戏卡成 PPT。
3. 关于 --fast 参数：这里的 fast 并不是指“压缩率低”，而是指跳过了耗时的算法试错，直接多线程拉满。它的压缩效果完全等同于老工具的 Level 9，但速度更快。
